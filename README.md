# EconNotes

Merhaba, EconNotes adında arkadaşlarımla beraber not paylaşılabilecek bir not paneli geliştirmeni istiyorum modern bir düzeyde. Arkadaşlar ve kullanıcılar, kayıt olmaları gerekiyor ilk kayıt segmenti ekleyebilirsin. Karşılama yazısı da ekle.
